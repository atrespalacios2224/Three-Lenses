# Three Lenses Image Lab

This folder is ready for GitHub Pages.

## Publish on GitHub

1. Create a new GitHub repository.
2. Upload `index.html`, `README.md`, and the entire `assets` folder.
3. Open the repository's **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.

GitHub will provide a public link after the site finishes publishing.

Do not move or rename the files inside `assets` unless you also update their paths in `index.html`.

## Image sources

The five historical photographs are from the Library of Congress. Source links and credits remain available inside the lab.
